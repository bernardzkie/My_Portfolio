## Run via GitHub

To publish this portfolio on GitHub Pages:

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to `Settings` → `Pages`.
4. Under `Source`, select `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`.
6. Save.

After a few minutes, the site will be available at `https://<your-username>.github.io/<repository-name>/`.

### Automatic deployment

A workflow is included at `.github/workflows/deploy.yml` to deploy the site automatically whenever `main` is updated.

Once the workflow runs, the portfolio will publish through GitHub Pages automatically.
